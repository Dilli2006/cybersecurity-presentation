### 🎯 Key Interactive Features
- **CIA Triad & Control Evidence:** Policy → Control → Audit evidence tabs
- **Interactive Risk Venn Model:** Live Asset × Threat × Vulnerability intersection
- **Colonial Pipeline (2021):** Visualized legacy VPN entry & pipeline shutdown
- **Uber (2022) MFA Simulator:** Live push spam fatigue & credential attack path
- **Equifax & AIIMS Delhi Incidents:** Patch enforcement and disaster recovery case studies
- **Live Password Policy Auditor:** Interactive entropy & common pattern analysis
- **Terminal Simulator:** Service baseline and port compliance
- **3D Risk Matrix & Heatmap:** Real-time likelihood × impact calculation with remediation toggles
- **Presenter Tools:** Speaker notes drawer (`N`), search palette (`Ctrl+K`), fullscreen mode (`F`)
